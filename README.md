# Pequenos-Projetos
Repositório dedicado a projetos pessoais que eu desenvolvo para adquirir conhecimento e/ou desenvolver meu portfólio.
Separados em níveis, todos estes arquivos foram programados em Python e a cada nível a dificuldade aumenta ao ser implementado uma ferramenta/estrutura nova.

# Níveis
Os níveis se referem a:
## Nível 1:
Funções e operadores relacionais e aritméticos
## Nível 2:
Persistência de dados em memória (array)
## Nível 3:
Persistência de dados em memória e dicionários
## Nível 4:
Persistência de dados em arquivo de texto (.txt e .csv)
## Nível 5:
Persistência de dados em banco de dados
## Nível 6: 
Programação orientada a objetos
## Nível 7:
Estrutura MVC
## Nível 8:
Estrutura MVC + Exportação de dados (biblioteca Pandas)
## Nível 9:
Estrutura MPA
